# Dify

Source: <https://dify.ai/>

**Dify** — open-source платформа для сборки AI-приложений: агентов, agentic workflows, RAG-ассистентов и чат-ботов. Подходит как ускоритель MVP: визуальный workflow, knowledge base, подключение моделей и инструментов, API для встраивания.

## Возможности

- Визуальные цепочки: вход → классификация / поиск / API → LLM → условие → действие.
- RAG-конвейер: загрузка документов, подготовка базы и поиск по ней.
- Подключение моделей, внешних API, собственных tools и плагинов.
- Публикация как web-app или использование через REST API.
- Логи выполнения и трассировка сценариев.
- Dify Cloud или self-hosted Community Edition через Docker.

## Практическое применение

Dify имеет смысл для короткого пилота, когда сначала нужно проверить экономику и качество AI-слоя, а не писать весь backend.

| Кейс | Workflow |
|---|---|
| AI-модерация UGC | Новая публикация → проверка правил / дублей / спама → одобрить / отклонить / ручная очередь → причина и лог |
| Performance-агентство | Данные рекламных кабинетов + CRM → метрики воронки → поиск отклонений → ежедневный отчёт и приоритетные действия |
| Внутренний помощник | Вопрос сотрудника → RAG по базе знаний → ответ с источниками или передача человеку |

## Границы

Dify не заменяет проектирование бизнес-процесса, интеграции, роли и права доступа, UX админки, проверку качества и работу с персональными данными. Для рискованных решений агент сначала должен работать в режиме рекомендации (human-in-the-loop), а не иметь право на финальное действие.

В production Dify может оставаться оркестратором AI-слоя, а критичные интеграции, БД и интерфейсы — быть кастомными. При росте требований к контролю, нагрузке или UX отдельные части стоит переносить в собственный сервис.

## Лицензия

Перед коммерческой перепродажей, white-label или enterprise-внедрением нужно сверить актуальные условия лицензии Dify: self-host не означает автоматически свободное коммерческое использование.
