# agent-doctor

Линтер дрейфа для системы ИИ-агентов Claude Code. Раз в неделю (или по кнопке) сам обходит инструкции твоих субагентов и скилов и находит места, где они разошлись с реальностью, — до того, как это выстрелит.

## Зачем

Когда у тебя не один агент, а несколько субагентов и скилов, их инструкции со временем протухают: ссылаются на удалённые файлы, держатся за отменённые концепции, сидят на невалидной модели. Ничего не падает с ошибкой — агент просто молча делает не то, а ты ловишь это задним числом по кривому результату. agent-doctor превращает эту невидимую проблему в понятный отчёт.

## Что проверяет

Универсально, без конфига:

- **DEAD PATH** — путь к файлу, на который ссылается инструкция, а его больше нет.
- **MODEL** — невалидная модель в frontmatter, плюс карта моделей всех агентов.
- **DEAD AGENT REF** — упоминание субагента, которого нет в реестре.
- **DEAD SKILL REF** — вызов скила, которого нет.
- **MISFILED** — файл в `agents/` без frontmatter `name:` (не агент, засоряет реестр).

Включается конфигом, под твою систему:

- **LIGHT MODEL** — «думающий» агент сидит на лёгкой модели (повод пересмотреть).
- **STALE FRAME** — твои отменённые формулировки/концепции, за которые агент ещё держится.

## Установка

Нужен только Python 3 (stdlib, ноль зависимостей). Положи `agent-doctor.py` куда удобно, например `~/.claude/tools/`.

```bash
python3 agent-doctor.py            # текст-отчёт
python3 agent-doctor.py --json     # машиночитаемо
python3 agent-doctor.py --quiet    # печатать только при находках (для cron)
python3 agent-doctor.py --config path.json   # явный конфиг
```

## Конфиг (опционально)

Все проверки под твою систему настраиваются конфигом. Он ищется по порядку: `--config` → переменная `AGENT_DOCTOR_CONFIG` → `./.agent-doctor.json` (в корне проекта) → `~/.claude/agent-doctor.config.json` (личный). Без конфига идут только универсальные проверки.

Скопируй `agent-doctor.config.example.json`, оставь нужные ключи (все опциональны). Самое полезное:

- `thinking_agents` — имена агентов, которым нельзя на лёгкой модели.
- `stale_patterns` — старые фразы/концепции, которые ты отменил; ловит агентов, застрявших в прошлом.
- `state_dir_prefixes` — где агент создаёт файлы на первой задаче (отсутствие там — мягкий warn, не ошибка).

## Автопрогон раз в неделю

macOS (launchd) — положи plist в `~/Library/LaunchAgents/`, запускает по расписанию и пишет отчёт в файл. Linux/cron — строка вида `0 10 * * 1 python3 ~/.claude/tools/agent-doctor.py --quiet >> ~/agent-doctor.log`.

## Про ложные срабатывания

Инструмент намеренно настроен консервативно: лучше промолчать, чем поднять ложную тревогу. Сигнализация, которая орёт по любому поводу, живёт ровно до того дня, когда её начинают глушить. Если agent-doctor подал голос — там правда что-то не так.
