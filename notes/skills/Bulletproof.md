# Bulletproof

Bulletproof - авторский 12-этапный воркфлоу от ресёрча до деплоя. Он превращает любую задачу в управляемый конвейер: исследование → план → критика → реализация → тесты → ревью → деплой. Это 12 ключевых промптов, обёрнутых в один скилл.

Ссылка на репозиторий: github.com/artemiimillier/bulletproof

Сначала аудит (используй промпт-аудит из блока «Безопасность» выше, подставив URL Bulletproof).

Если вердикт «безопасно» - устанавливаем локально в проект
