# Что такое skills

Скилл - это папка с инструкцией, которую Claude подтягивает сам, когда видит подходящий триггер. Один скилл умеет делать дизайн, другой - парсить PDF, третий - проводить 12-этапный воркфлоу от ресёрча до деплоя.

В апреле 2026 это самая горячая тема в сообществе Claude Code. Karpathy уже называет этот подход agentic engineering - ты не пишешь код, ты оркестрируешь агентов со скиллами.

Как устроен скилл изнутри
Разберём механику, чтобы ты не относился к скиллам как к «магии».

Скилл - это папка в .claude/skills/название-скилла/. Внутри:

SKILL.md - главный файл. Это по сути сохранённый промпт-инструкция: «когда тебя позвали этим скиллом - прочитай вот эти файлы, действуй вот так, возьми информацию отсюда-отсюда, сформируй результат в таком формате».
Опциональные файлы - шаблоны отчётов, примеры, скрипты-помощники, данные, на которые ссылается SKILL.md.
Триггер - короткое описание в начале SKILL.md, которое Claude видит при старте сессии. Когда ты пишешь задачу, подходящую под триггер - Claude сам подгружает содержимое скилла.
Проще говоря: скилл = твой персональный промпт, отчуждённый в папку, чтобы его можно было переиспользовать без копипасты.

Есть два уровня установки:

Глобальные: ~/.claude/skills/ - доступны во всех проектах на твоём компьютере.
Локальные (проекта): .claude/skills/ в корне проекта - доступны только в этом проекте.
🎯 Правило: ставь локально, если скилл нужен конкретному проекту. Глобально - только то, чем реально пользуешься везде. Чем меньше скиллов подключено - тем меньше токенов тратится на их триггеры в каждом сообщении.
