# Interfaces skills

> [[Interfaces — агентские skills для UI-ревью]] — исходный репозиторий и подробный capture.

Коллекция `better-*` skills разделяет UI-review на семь независимых областей: orchestration, UI-polish, typography, colors, accessibility, layout и UX-writing. Её сильная сторона — не «сделать красиво», а явное владение правилами: доступность определяет требования, а цвет, текст и layout — соответствующие технические решения.

## Применение

Для клиентского или внутреннего веб-интерфейса: сначала определить бизнес-задачу и сценарий, собрать функциональный flow, затем прогнать полный review через `better-interface`. Узкие skills применять только к найденной проблеме или зоне риска.

## Граница

Это слой качества интерфейсной реализации, не метод выбора продукта или валидации спроса. Установка в агентскую среду требует отдельного аудита безопасности и совместимости.
