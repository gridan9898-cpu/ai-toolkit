# Caveman skill

`caveman` — skill/plugin для ультра-краткого режима ответов агента: меньше токенов, меньше воды, при сохранении технической точности.

Репозиторий: https://github.com/juliusbrussee/caveman

## Для чего

- Сжимать ответы агента без потери смысла.
- Экономить токены в длинных сессиях.
- Держать коммуникацию короткой: проблема → причина → действие.
- Использовать как референс для token-efficient режима в AI-операторе.

## Важный вывод

Это не обязательный skill для установки. Ценность — как пример формата: короткие ответы, минимум filler-текста, технические термины и команды остаются точными.
