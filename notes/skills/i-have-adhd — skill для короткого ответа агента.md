# i-have-adhd — skill для короткого ответа агента

Источник: [ayghri/i-have-adhd](https://github.com/ayghri/i-have-adhd) · README и GitHub API проверены 02.08.2026 · лицензия MIT.

## Что это

**i-have-adhd** — skill для coding agents, который задаёт формат ответа: сначала действие, затем короткие нумерованные шаги, без преамбулы и лишних отступлений, с одним конкретным следующим шагом в конце. Название не означает диагностику: это стиль коммуникации с агентом.

README описывает установку как plugin для Claude Code и Codex.

## Зачем Данилу

Полезен как набор правил для рабочих ответов агента: быстрее увидеть, что сделать сейчас, состояние работы и критерий завершения. Это ближе к коммуникационному контракту, чем к новой технической возможности.

## Применение

- Сверить десять правил с текущими инструкциями агента и заимствовать только те, что реально уменьшают шум.
- Тестировать в отдельной агентной конфигурации на 2–3 реальных coding-задачах, затем оставить или убрать по качеству результата.

## Ограничения

- Skill оптимизирует подачу, но не качество исследования, кода или проверки результата.
- Жёсткое сокращение может скрыть важные риски и альтернативы; для архитектурных, security- и исследовательских задач нужна достаточная аргументация.
- Не устанавливать поверх существующих global instructions без diff-а: правила могут конфликтовать с текущим стилем и tool-use дисциплиной.
