# Hermes Agent Skills Hub

## Что это

Официальный **Skills Hub** Hermes Agent — веб-каталог для поиска и установки skills из встроенных, optional и community-реестров. На странице есть поиск, категории и фильтрация по источнику skills; сам каталог подгружается динамически.

## Что подтверждено по первоисточнику

- Раздел называется *Skills Hub* и позиционируется как место, где можно discover, search и install skills.
- Интерфейс показывает разбиение на **Built-in**, **Optional** и **Community**, а также работу с несколькими registries.
- На момент проверки интерфейс сообщал, что загружает каталог «88k+ skills across every registry». Это динамический счётчик страницы, не независимая проверка количества или качества skills.

## Зачем Данилу

Это не источник для массовой установки. Это входная точка, когда под конкретную задачу есть понятный пробел в возможностях Hermes: сначала найти кандидатов, затем проверить репозиторий, автора, код/инструкции, требуемые доступы и реальную совместимость с текущим профилем Hermes.

## Практика использования

1. Искать skill только под конкретную задачу и с заранее понятным критерием результата.
2. До установки проверять содержимое `SKILL.md`, скрипты, сеть, доступы к файлам и секретам.
3. Не путать skill из каталога с уже установленным: живой список установленного на машине ведётся отдельно в `registry/registry.md`.
4. После теста фиксировать в этой базе результат: что делает, ограничения, совместимость с Hermes и решение — ставить / не ставить.

## Ограничения

- Каталог не является гарантией безопасности, качества или актуальности конкретного skill.
- Карточка/описание не заменяет ревью инструкций и исполняемых файлов.
- Совместимость skill, написанного под другой агентный рантайм, нужно подтверждать в изолированном тесте; не переносить глобально по умолчанию.

## Связи

- `registry/registry.md` — фактически установленные skills/plugins/MCP на машине.
- `notes/skills/Безопасность skills.md` — критерии безопасного разбора skills.
- `notes/skills/Что такое skills.md` — базовая модель skills.
