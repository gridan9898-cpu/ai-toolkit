# Playwright MCP

Зачем:

Сделал лендинг - Claude сам открывает его, проверяет формы, отлавливает ошибки, шлёт тебе скриншоты.
Надо протестировать чужой сайт - Claude прогоняет сценарий и пишет отчёт.
Регрессия после правки - автоматический прогон, чтобы убедиться, что ты ничего не сломал.
⚠️ У некоторых Playwright работает нестабильно, у других - идеально. У меня работает идеально - но если у тебя полезут странности, не зависай, поставь альтернативу (например, Chrome DevTools MCP) и иди дальше.

Промпт для агента:
```
Установи Playwright MCP в мой текущий проект Claude Code.

1. Найди официальный пакет (Microsoft Playwright MCP или @modelcontextprotocol/playwright).
2. Проведи аудит безопасности - это ведь браузер с полным доступом, важно понять, что он делает.
3. Если безопасно - установи ЛОКАЛЬНО для этого проекта (в .mcp.json или настройки Claude Code этого проекта, НЕ глобально).
4. После установки покажи, как его вызывать, какие команды доступны (navigate, click, screenshot, fill и т.д.).
5. Сделай проверочный прогон: открой google.com, сделай скриншот, покажи мне.
```

Проверка - твой первый автотест
Как только у тебя будет лендинг, попробуй:

Промпт для агента
```
Используй Playwright MCP. Открой мой локальный сайт по адресу http://localhost:3000.

1. Сделай скриншот первого экрана.
2. Прокрути страницу вниз до конца - сделай скриншот каждого блока.
3. Найди главную форму (кнопка «Купить» / «Оставить заявку»), заполни её тестовыми данными (имя: Тест, email: test@example.com), нажми кнопку.
4. Что произошло после отправки? Скриншот результата.
5. Переключи viewport на мобилку (iPhone 14). Повтори прогон.
6. Собери отчёт: что работает, где баги, какие блоки выглядят плохо на мобилке.
```

Claude пойдёт и всё сделает. Ты получишь полноценный тестовый отчёт со скриншотами - и ни строчки кода сам не написал.
