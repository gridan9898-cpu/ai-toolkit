# Что такое MCP

MCP (Model Context Protocol) - стандартизированный способ подключить Claude к любому внешнему сервису: Google Sheets, Gmail, Notion, CRM, твоему API, базе данных.

Аналогия: представь USB-хаб, куда любой сервис может воткнуть свой «коннектор». Клод с одной стороны, сервис с другой - общаются через общий стандарт, без документации и без кастомной интеграции.

Отличие от обычного API: API у каждого свой - логика, названия эндпоинтов, авторизация. MCP - единый протокол. Клод подключается одинаково к любому MCP-серверу и сразу знает, что с ним делать.

Как использовать:

У сервиса, с которым тебе нужно работать - спроси Клода:
```
Есть ли MCP-сервер для [название сервиса, например Google Sheets]? 
Если да - дай ссылку и команду установки (локально в этот проект). 
Если нет - есть ли у этого сервиса открытое API? 
Если да - прочитай документацию и покажи, как подключиться.
```

Если MCP есть - ставишь через [[Аудит skills]] → [[Локальная установка skills]] (те же два промпта, что и для скиллов).
Если только API - Claude напишет тебе скрипт-адаптер под твой проект.
Важно: каждый подключённый MCP добавляет ~2000 токенов в контекст при каждом сообщении (даже если ты с ним сейчас не работаешь). Не подключай десятки MCP «на всякий случай» - держи только те, которыми активно пользуешься.
