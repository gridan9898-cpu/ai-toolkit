# Smithery

Зайди на smithery.ai и выбери один скилл под свою идею:

делаешь лендинг → Frontend Design / UI Generation (если не хватает стандартного)
работаешь с клиентами → CRM / Email / Slack
парсишь сайты → Browser / Scraping
аналитика/дашборды → Google Sheets / Notion / Airtable
контент → Content / Marketing
Правила: не ставь всё подряд. Каждый лишний скилл жрёт токены контекста при каждом сообщении. Один - два реально нужных скилла лучше, чем десять «на всякий случай».

Используй те же два промпта ([[Аудит skills]] → [[Локальная установка skills]]), что и для скиллов Anthropic.
